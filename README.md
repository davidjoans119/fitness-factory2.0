# Fitness Factory 2.0 — Website Demo

A responsive one-page gym website demo built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Internet access is needed for the Google Fonts and remote Unsplash photography.

## Before handing over to the gym
- Confirm the address and map pin with the owner.
- Add the gym's verified WhatsApp number in `script.js` at `GYM_WHATSAPP_NUMBER` (digits only, country code included, e.g. `919876543210`). The enquiry form then opens a pre-filled WhatsApp message.
- Replace stock Unsplash images with photographs of the actual gym.
- Confirm current membership prices, early-bird offer validity, PT inclusions and operating hours with the owner.
- The enquiry form is a front-end demo. Until a valid WhatsApp number is added, it formats and copies the enquiry message; it does not store submissions in a database.
